# 출처와 공개 정리

현재 공개 자료는 개인 후속 실험과 팀 백엔드의 재사용 범위를 구분합니다. Git source는 `sleepBE`의 `origin/feat/rag-parallel-retrieval-v3`, commit `317a9289df3556916bc2fa88ed8d7d200ef31b4c`에서 읽었습니다. 원본 Git 이력을 새 저장소 이력으로 합치거나 과거 날짜의 커밋을 만들지 않았습니다.

| 시점 | 근거 |
|---|---|
| 2025-12-02 | 초기 client 벤치마크 CSV와 분석 결과 |
| 2025-12-03~10 | 병렬 전략·실행 모드·단계 계측 관련 Git 변경 |
| 2025-12-10 | 최종 보고서 및 서버 타이밍90건 |
| 2026-09-09 | 보고서 기반 공개 정리, 신규 측정 계약 검사기 |
| 2026-09-10 | 원본 코드/로그 복구, 수치 재집계, schema 검사와 결과 그림 공개 |

`legacy/`는 당시 소스를 보존한 자료입니다. 원본의 실행 문제도 고쳐진 과거처럼 꾸미지 않았습니다. `scripts/reproduce_historical.py`와 관련 tests/docs는 2026년 신규 작업입니다.

원본 source/결과와 공개본의 SHA-256은 [source-manifest.json](source-manifest.json)에서 확인할 수 있습니다. 같은 데이터의 복사본은 여러 독립 실험으로 세지 않았습니다.

전체 bootrun 로그, secret/config 원본, 개인정보가 있는 표지, 제3자 논문·서적·데이터는 공개 대상에서 제외했습니다. 보고서는 표지와 개인정보 metadata를 제거한 파생본입니다. 원본 로컬 파일은 보존했습니다.
