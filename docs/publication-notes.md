# 공개 자료 범위

이번 요청에서 프로젝트 source 공개가 허용되어 검토한 개인 실험 source, 개인정보 없는 측정자료와 결과 이미지를 복구했습니다. 팀 서비스 전체 작성권한과 개인 확장 기여는 구분합니다.

원본 이력을 가져오지 않고 검토된 현재 snapshot만 공개합니다. 원본 전체 로그/credential/config개인정보/제3자 코퍼스는 제외합니다. 보고서 표지의 개인식별정보와 PDF metadata를 제거한 파생본을 제공하며 원본을 수정하지 않았습니다.

재배포 license를 임의 생성하지 않았습니다. 공개되었다는 사실만으로 제3자에게 무제한 재사용 권한이 생기는 것은 아닙니다.
