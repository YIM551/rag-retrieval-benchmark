# 과거 보고서 읽기와 정정

[개인정보를 제거한 2025년 보고서](historical-report-anonymized.pdf)는 표지를 제외한22쪽입니다. 인쇄 페이지2~23을 보존했습니다. 원본 실험 당시 주장을 그대로 확인하기 위한 자료이며 다음 정정을 함께 적용합니다.

1. '최악의 응답시간'은 max가 아니라 p95를 가리키는 문맥이 있으므로 p95로 읽습니다.
2. 통계적 유의성·실서비스 적용 가능성은 반복실험/신뢰구간/품질/부하 테스트로 입증되지 않았습니다.
3. 스레드 오버헤드가 성능 악화의 원인이라는 설명은 당시 해석입니다. 독립 프로파일링 증거가 없습니다.
4. 검색 구간에는 필터/MMR/citation 구성이 포함되나 실제 prompt build(contextMs)는 밖에서 계측됩니다. 병렬 세부 작업시간 합으로 RetrievalMs를 만들면 안 됩니다.
5. 최종 표의 SEQUENTIAL 평균(초) 셀 오타는 10.72283초입니다. 원 숫자10722.83ms를 기준으로 계산합니다.
6. 부록에 언급된 코드와 복구한 최종 source의 출력 필드/가이드가 일부 다릅니다. 실제 source 위치와 parser를 우선합니다.
7. 초기 client CSV와 최종 서버 로그는 다른 실험입니다. 성능이 좋아 보이는 초기 수치만 선택하지 않습니다.

원자료90건 재집계로 표5-2/5-3 주요 평균 및 전체p95의 일치는 확인했습니다. 그 일치가 모든 실험 조건 통제나 검색 품질까지 입증하지는 않습니다.
